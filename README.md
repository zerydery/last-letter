# 🎮 Sambung Kata Helper

Website helper kosakata untuk game Roblox **Sambung Kata (Last Letter)**.  
Temukan kata bahasa Indonesia berdasarkan huruf awal dengan cepat!

🔗 **Live:** [sambungkata.netlify.app](https://sambungkata.netlify.app) _(ganti dengan URL Netlify kamu)_

---

## ✨ Fitur

- 🔍 **Real-time search** — ketik huruf, hasil langsung muncul
- 📚 **1.299+ kata** bahasa Indonesia (termasuk `ng-`, `ny-`)
- 🔥 **Badge merah** pada kata berakhiran huruf sulit (c, f, q, v, w, x, y, z)
- 📋 **Klik kata → salin** otomatis ke clipboard
- 💾 **Riwayat tersimpan** di browser (localStorage)
- 🔀 Filter panjang · Sort terpendek/terpanjang/A–Z/🔥 Sulit dulu
- 📱 Responsive mobile-first

## 🚀 Cara Pakai

1. Buka website
2. Ketik huruf terakhir kata lawan
3. Klik kata yang dipilih → tersalin otomatis
4. Paste ke chat Roblox!

## 🛠 Tech Stack

Pure HTML + CSS + JavaScript — no dependencies, no build step.

## 📁 Struktur

```
├── index.html      # Halaman utama
├── style.css       # Dark glassmorphism styling
├── app.js          # Logic + database kata
└── netlify.toml    # Konfigurasi Netlify
```
